# スタイルクラス一覧

> 対応ソース: `style.css`

スタイル変更はここに挙げたクラス名で指定できる（例: 「`.task-card` の余白を」「`.reward-badge` のフォントを」）。

## 方針

- **意味のある反復ブロック**（カード・チップ・バッジ・ボタン・行など）だけをクラス化している。flexラッパー・グリッド列・グラフ描画などの一回限りのレイアウトは意図的にインラインのまま。
- **状態で変わる値**（背景色・ボーダー色・opacity・display など）はインライン `style={{}}` に残し、クラスは静的プロパティのみを持つ（インラインがクラスを上書きする想定）。
- 状態の見た目はモディファイアクラス（`.is-*`）で切り替える。色は `:root` の CSS 変数で一元管理（変数一覧は `CLAUDE.md` の「カラーシステム」）。

## 命名規約

| 種類 | 例 |
|---|---|
| カード | `.barter-card` `.craft-card` `.hideout-card` `.task-card` |
| バッジ / チップ | 既存の `.badge-*` を流用、`.task-chip` `.profit-badge` |
| ボタン | 既存の `.btn` `.btn-*` に寄せる |
| ポップオーバー | `.popover` |
| 行 / セクション | `.setting-row` `.list-row` `.stat-box` |

## 状態モディファイア

| クラス | 状態 |
|---|---|
| `.req-chip.is-ok` `.obj-chip.is-ok` `.ll-badge.is-ok` | 充足・OK |
| `.ll-badge.is-locked` | 未解放 |
| `.taskrow-btn.is-pinned` / `.is-progress` / `.is-done` | ピン止め / 進行中 / 完了 |
| `.delivery-chip.is-checked` / `.is-stocked` | 納品チェック済み / 在庫あり |

## 変数化していない色（意図的）

- `TAG_COLORS`（プロジェクトタブの色。localStorage に保存されるため生hexのまま）
- テーマ定義の基礎色（`THEMES`）
- 一回限りの装飾色: `#f97316`（ストリークの炎）、`#4ade80`（信頼度の＋値）、`#450a0a`（`.alert-one` 背景）、部品固有の濃背景（`#0a1a0a` `#1a2e1a` `#1e2536` など）
