# プリセット機能仕様書（武器プリセット比較）

> 対応ソース: `src/js/33-tab-presets.js`（画面・計算）、`src/js/10-app-state.js`（state・保存）、`src/js/00-constants.js`（`QUERIES.weaponMods`）

タブ id: `presets` / ラベル: 「プリセット」 / アイコン: `tool` / タブ見出し: 「武器プリセット比較」

自分で組んだ武器プリセット（パーツ構成）を登録し、**入手価格・エルゴ・反動などを比較**するタブ。パーツの mod 補正値から理論値を自動計算し、スロット（カテゴリ）別のおすすめモッドも一覧できる。

> GraphQL 停止中（JSON API フォールバック中）は `apiData.weaponMods` が空になるため、価格以外の理論値計算とおすすめモッドが使えない（タブバーでは半透明表示・`restricted: true`）。

---

## データ構造

### `eft_presets_v1`（localStorage・全モード共通）

```json
[
  {
    "id": "preset_1720000000000",
    "name": "M4 低反動",
    "weapon": "M4A1",
    "ergo": 52,
    "vrecoil": 48,
    "baseErgo": 50,
    "baseVrecoil": 56,
    "baseHrecoil": 230,
    "baseMOA": 2.86,
    "parts": [
      { "itemId": "5c78f2612e221600114c9f0d", "itemName": "SureFire SF3P 5.56x45 flash hider", "qty": 1 }
    ]
  }
]
```

| フィールド | 説明 |
|---|---|
| `id` | `'preset_' + Date.now()` |
| `name` | プリセット名（新規作成時は「新しいプリセット」） |
| `weapon` | 武器名（自由入力。武器フィルターのグループ分けに使用） |
| `ergo` / `vrecoil` | 手入力のエルゴ / 垂直反動（理論値が計算できない場合の表示値・ソート値） |
| `baseErgo` / `baseVrecoil` / `baseHrecoil` / `baseMOA` | 素の武器のスタッツ（理論値計算の基準。0 = 未入力） |
| `parts` | パーツ構成 `[{ itemId, itemName, qty }]`。同じアイテムを追加すると `qty` が増える |

### `eft_presets_standard`（localStorage・全モード共通）

「標準プリセット」に設定したプリセットの `id`（解除時はキー削除）。

## 画面構成

### 1. ヘッダー

- 「プリセット追加」ボタン: 新規プリセットを作成して展開する（武器フィルター選択中はその武器名を初期値にする）。
- API未取得時: 「フリマ価格を表示するには『APIデータ取得』を先に実行してください。」
- **武器フィルター**（登録済み武器名が1件以上のとき）: 「すべて」＋武器名ボタン。再クリックで解除。
- **ソート**: 「価格 安い順」/「エルゴ 高い順」/「垂直反動 低い順」（エルゴ・反動は理論値があれば理論値、なければ手入力値で比較）。
- **「『{標準プリセット名}』の共通部品を非表示」チェック**（標準プリセット設定時のみ）: 各プリセットのパーツ一覧から標準プリセットと同じ部品を隠し、差分だけを表示する。

### 2. プリセット一覧（表）

列: 標準マーク（`anchor`）/ プリセット名（武器名タグ付き）/ エルゴ / 垂直反動 / フリマ推定価格。行クリックで展開（同時に開けるのは1件）。

### 3. 展開パネル

| 要素 | 内容 |
|---|---|
| 編集フィールド | 武器名（既存の武器名を候補表示）・プリセット名・エルゴ・垂直反動 |
| ベース武器スタッツ | 素エルゴ・素垂直反動・素水平反動・素MOA を入力 → 「→ 理論値: エルゴ / 垂直 / 水平 / MOA / 重量」を表示。「エルゴ・反動に反映」ボタンで理論値を手入力欄（`ergo`/`vrecoil`）にコピー |
| ボタン群 | 「標準に設定 / 標準を解除」・「複製」（名前に「（コピー）」を付けて新規作成）・「削除」（ネイティブ `confirm`。標準プリセットなら標準も解除） |
| パーツ構成 | 「パーツ構成 (N件) 合計 ₽X」。共通部品を非表示中は「N件を非表示 差分 ₽Y」も表示 |
| パーツ行 | アイコン・カテゴリタグ・名前・単価（× 個数 = 小計）と入手元・個数の －／＋（最小1）・削除（×） |
| パーツ追加検索 | 2文字以上で `apiData.items` を名前/略称で部分一致検索（最大15件）。↑↓ で選択、Enter で追加（未選択なら先頭）、Esc でクリア |

パーツ0件: 「パーツが登録されていません。下の検索欄から追加してください。」
差分なし: 「標準プリセットと同じ部品のみで構成されています（差分なし）。」

### 4. スロット別モッドおすすめ（折りたたみ・初期は閉）

- **サマリーバー**: 展開中のプリセットのエルゴ / 垂直反動 / 水平反動 / MOA / 重量 / 推定コスト。理論値なら「理論値」、素値が未入力なら「素値未入力」と小さく表示。プリセット未展開時は「プリセットを展開すると理論値がここに表示されます」。
- **カテゴリタブ**: `apiData.weaponMods` の先頭カテゴリ名一覧（文字コード順）。展開中プリセットの部品が1つも無いカテゴリには赤い点を付ける（未装着スロットの目安）。
- **優先ソート**: 「エルゴ修正 高い順」/「反動修正 低い順」/「精度修正 低い順」。上位25件を表示。
- **モッド表**: 名前（略称）・エルゴ・垂直反動（%）・精度（%）・最安値（入手元）・追加/削除ボタン。良い値は緑、悪い値は赤。展開中プリセットに含まれる行はアクセント色で強調し、「削除」ボタンに切り替わる。プリセット未展開時は「追加」が無効。

## 計算ロジック

### 最安入手価格（`getBestPrice` / `getBestPriceInfo`）

1. フリマ 24h 平均（`avg24hPrice`）を初期値にする（入手元ラベル「フリマ」）。
2. `buyFor` のトレーダー販売のうち、**設定タブのトレーダーLL（`traderStatus[id].ll`）で購入可能なもの**（`minTraderLevel` 以下）を比較し、より安ければ置き換える（入手元ラベル「トレーダー名 LLn」）。
3. どちらも無ければ 0（「価格不明」）。

プリセット価格（`getPresetPrice`）= 各パーツの最安価格 × 個数 の合計。

### 理論値（`calcPresetStats`）

`apiData.weaponMods` からパーツの mod 補正値を個数分合計する。

| 項目 | 計算式（素値が 0 = 未入力なら `null`） |
|---|---|
| エルゴ | `baseErgo + Σ ergonomics` |
| 垂直反動 | `baseVrecoil × (1 + Σ recoilModifier)` |
| 水平反動 | `baseHrecoil × (1 + Σ recoilModifier)` |
| MOA | `baseMOA × (1 + Σ accuracyModifier)`（小数2桁） |
| 重量 | `Σ weight`（パーツのみ・kg） |

補正値も素値も無いプリセットは `null`（理論値なし → 手入力値を表示）。

## 使用する API データ

| データ | クエリ | 用途 |
|---|---|---|
| `apiData.items` | `QUERIES.items` | パーツ検索・価格（`avg24hPrice` / `buyFor`）・カテゴリ・アイコン |
| `apiData.weaponMods` | `QUERIES.weaponMods` | mod 補正値（`properties.ergonomics` / `recoilModifier` / `accuracyModifier`）・重量・カテゴリ・価格 |

`weaponMods` の `properties` は `ItemPropertiesWeaponMod` の場合のみ値を持つ。フォアグリップ等それ以外の型も、おすすめ一覧には補正値 0 として表示する。

## 既知の課題

- JSON API フォールバック中は `weaponMods` が空（理論値・おすすめ不可）。
- おすすめモッド表の「プリセットに含まれる」行の目印に `▶`（U+25B6）を文字で使っている。アイコンルール（`<Icon>` で統一）に合わせて置き換えるのが望ましい。
