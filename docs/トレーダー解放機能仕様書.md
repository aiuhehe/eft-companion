# トレーダー解放（LLアドバイザー）機能 — 機能詳細・実装仕様

> 対応ソース: `src/js/21-tab-advisor.js`

> 最終更新: 2026-06-17

## 概要

各トレーダーの**次のロイヤルティレベル（LL）解放条件**（プレイヤーレベル・信頼度・取引額）を現在のステータスと突き合わせ、達成状況と優先度を一覧表示する。「あと何が足りないか」を一目で把握し、次に上げるべきトレーダーを判断する支援機能。

> UIアイコンは全てSVG `<Icon>`。達成/未達は `circle-check` / `circle-x`。

---

## データソース

GraphQL `traders` から各 LL の解放条件を取得。

```graphql
traders {
  id name
  currency { shortName }
  levels {
    level
    requiredPlayerLevel
    requiredReputation
    requiredCommerce
  }
}
```

`TRADER_LIST`（定数・[eft-tool.html:45](eft-tool.html)）でトレーダー定義を保持。`noCommerce: true` のトレーダー（Fence・Ref）は取引額要件なし（信頼度のみ）。

---

## 入力ステータス

設定タブで入力した `traderStatus` を参照。

```
traderStatus[traderId] = { ll, rep, commerce }
  ll       : 現在のロイヤルティレベル（1〜）
  rep      : 現在の信頼度（ゲーム内表示値・エディションボーナス込み）
  commerce : 累計取引額
playerLevel : プレイヤーレベル（共通ステータス）
```

> 信頼度はゲーム内表示値をそのまま使う（エディションボーナスを別途加算しない）。

---

## 判定ロジック（`traderAnalytics` useMemo）

各トレーダーについて「現在LL+1」の解放条件と比較する。

```
nextLevelData = trader.levels.find(level === currentLL + 1)
  無ければ（=最大LL）スキップ

reqLevel    = requiredPlayerLevel
reqRep      = requiredReputation
reqCommerce = requiredCommerce
noCommerce  = TRADER_LIST定義 or reqCommerce === 0

levelOk    = playerLevel >= reqLevel
repOk      = effectiveRep >= reqRep
commerceOk = noCommerce or commerce >= reqCommerce
```

### 優先度（priority）

| priority | ラベル | 条件 | 行背景 |
|---|---|---|---|
| `urgent` | 最優先 | レベル・取引額OK だが**信頼度だけ不足** | `--danger-bg-weak` |
| `soon` | あと少し | 未達条件が **2個以下** | `--warn-bg-weak` |
| `far` | 遠い | 未達条件が **3個** | 透明 |
| `ok` | OK | 全条件達成 | 透明 |

`urgent` は「タスクを消化すれば信頼度が上がって解放できる」状態を示すため最優先扱い。
備考欄（reason）には不足分（`レベルがあと N 不足` / `信頼度があと N 不足` / `取引額があと N {通貨} 不足`）を表示。

### 通貨判定
`trader.currency.shortName` から `USD` / `EUR` / `RUB` を判定し、`getCurrencySymbol` / `fmtCurrency` で整形。

## 表示（テーブル）

| 列 | 内容 |
|---|---|
| トレーダー | 名前（アクセント色） |
| LL | `LL{現在}→{次}` |
| 優先度 | 色付きドット＋ラベル（`.priority-badge`） |
| プレイヤーLv | `circle-check`/`circle-x` ＋ `現在 / 必要` |
| 信頼度 | 同上 ＋ `現在 / 必要` |
| 取引額 | 同上 ＋ `現在 / 必要`（noCommerce は `—`） |
| 備考 | 不足内容 |

### ソート（`advisorSort`）
- `priority`（既定）: urgent → soon → far → ok
- `commerce`: 取引額不足が少ない順（達成済みは最上位）
- `level`: レベルに近い順（達成済みは最上位）
- `close`: 未達条件数が少ない順（総合・達成に近い順）

ソート前の既定並びは `traderAnalytics` 内で `{urgent:0, soon:1, far:2, ok:3}` 順。
