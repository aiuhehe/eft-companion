# アーマープレート一覧 機能仕様書

## 概要

tarkov.dev API から取得したアーマープレートデータを、アーマークラス別に表示するタブ。比べる順番（クラス → 耐久値 → ブラント透過率）に合わせて列を並べている。

## タブ情報

| 項目 | 値 |
|---|---|
| タブ ID | `armor` |
| アイコン | `lock` |
| ラベル | 装甲板 |
| フルラベル | アーマープレート一覧 |
| ソースファイル | `src/js/33-tab-armor.js` |

## フィルタ（2026-11-10 改訂）

上部に弾薬タブと同じ**縦並び**（ラベル列＋ボタン列のグリッド・`.armor-filters`）で「クラス」「部位」の2行を置く。どちらも**複数選択**のトグルで、選んだもののどれかに当てはまるプレートを表示する（行の中は OR、クラスと部位は AND）。

| 行 | ボタン | state | 選択中の色 |
|---|---|---|---|
| クラス | 全て / データにあるクラス（高い順・`armorClassOptions`。現在は 6 / 5 / 4 / 3 / 1） | `armorClasses`（number[]） | アクセントカラー |
| 部位 | 全て / `FR. PLATE` / `BCK. PLATE` / `L. PLATE` / `R. PLATE`（`ARMOR_ZONE_FILTERS`） | `armorZones`（`'front'`/`'back'`/`'left'`/`'right'`[]） | `--info` |

- 「全て」= 空配列。「全て」を押すとその行の選択を全部外す。個別ボタンをすべて選んだ状態になったら自動で「全て」に戻す。解除ボタンは無い（「全て」で代わりになる）。
- ボタンは両行とも `.armor-filter-btn` で形・太字・ホバーを共通化。行ごとの違いは選択中の色だけ（`.is-class` / `.is-zone` が `--filter-color` を切り替え、選択中は枠・文字がその色、背景はその色の 18% 透過）。
- 部位の判定は `04-helpers.js` の `armorZoneKind(表示名)` → `'front' | 'back' | 'left' | 'right'`。`FR. PLATE` と `F. PLATE`（Korund 系の前面）はどちらも `front`。未翻訳の生キー（`..._chest` / `_back` / `side_left_*` / `side_right_*`）や英語表記にも対応する。
- 絞り込みの結果、0件になったクラスはセクションごと表示しない。全クラス0件なら「選択したクラス・部位に合うプレートはありません。」を表示。

## 表示レイアウト

アーマークラスごとにセクション分け（Class 6 → 1 の降順）。各セクション内は既定で耐久値の降順。

各セクションの先頭に列見出し行（クラス / 耐久値 / ブラント / 名前 / 部位 / 入手手段）がある。「ブラント」見出しはボタンで、**クラスごとに独立して**並び順を切り替える（state: `armorBluntSort` = `{ [cls]: 'asc' | 'desc' }`）:

| 状態 | 並び順 | 見出しのアイコン |
|---|---|---|
| 未設定（既定） | 耐久値の高い順 | `sort` |
| `asc` | ブラント透過率の低い順（同率は耐久値の高い順） | `chevron-up` |
| `desc` | ブラント透過率の高い順（同率は耐久値の高い順） | `chevron-down` |

クリックごとに 未設定 → `asc` → `desc` → 未設定 と巡回する。ソート中は見出しがアクセントカラーになる。

### グリッド列構成（1行）

列幅は `ARMOR_GRID_COLS`（`04-helpers.js`）で見出し行とデータ行が共有する。

| 列 | 内容 | 幅 |
|---|---|---|
| クラスバッジ | `Cls N`（クラスカラーで色分け） | 40px |
| 耐久値 | `properties.durability`（アクセントカラーバッジ） | 52px |
| ブラント透過率 | `properties.bluntThroughput × 100`（%表示） | 66px |
| アイコン | `iconLink` 画像 | 34px |
| 名前 | アイテム名 | minmax(130px, 1fr) |
| カバーゾーン | `properties.zones` を小チップで表示 | minmax(0, 0.8fr) |
| 入手手段 | トレーダー販売 / フリマ / バーター / クラフト | minmax(0, 1.4fr) |

## APIデータ

クエリ: `QUERIES.armorPlates(gm, lang)` → `items(type: armorPlate)`

取得フィールド:
- `id`, `name`, `shortName`, `iconLink`, `wikiLink`
- `avg24hPrice`
- `buyFor` → `vendor`（名前・normalizedName・minTraderLevel・taskUnlock）
- `bartersFor` → trader, level, taskUnlock
- `craftsFor` → station（id・name）, level
- `properties → ItemPropertiesArmorAttachment`: `class`, `material`, `bluntThroughput`, `repairCost`, `speedPenalty`, `turnPenalty`, `ergoPenalty`, `zones`, `durability`

state キー: `apiData.armorPlates`（`loadAPIData` 内で並列取得）

## JSON API フォールバック時のデータ取得元（2026-11-10）

GraphQL が使えないとき（停止中・シーズンモード）は `01-api.js` の `fetchJsonApiFallback` が `_detectItemQueryKind()` で `type: armorPlate` を判定し、`_loadItemDetailContext` の共通データ（`json.tarkov.dev/{mode}/items` 翻訳済み・`traders`・`tasks`・`hideout`・`barters`・`crafts`）から `_itemDetailTransforms.armorPlate` で GraphQL と同じ形に変換して返す。タブ側のコードはモードに関係なく同じ。フォールバック中もタブバーで半透明表示にはしない（`restricted` なし）。

| フィールド | 変換 |
|---|---|
| 対象 | `types` に `armorPlate` を含み、`properties.propertiesType === 'ItemPropertiesArmorAttachment'` の items |
| `class` / `durability` / `bluntThroughput` / `repairCost` / `speedPenalty` / `turnPenalty` / `ergoPenalty` | `properties` からそのまま |
| `zones` | `properties.zones`（`Armor Zone Plate_Granit_SAPI_chest` 形式）は items ロケールで翻訳済み（`FR. PLATE` / `BCK. PLATE` / `L. PLATE` / `R. PLATE` 等）。`side_left_high` と `side_left_low` が同じ `L. PLATE` に訳されるため**重複を除く** |
| `material` | ID 文字列（`Ceramic` 等）→ `{ name }`。`items.armorMaterials[ID].name`（`MatCeramic` → 翻訳済み「セラミック」等）。未翻訳なら ID をそのまま使う |
| `wikiLink` / `avg24hPrice` | items からそのまま（`noFlea` のプレートは `avg24hPrice` が null） |
| `buyFor` | `_makeBuyFor`（`buyFromTrader` → トレーダー販売・`taskUnlock` はタスク名解決済み。`noFlea` でなければ `lastLowPrice`（無ければ `avg24hPrice`）でフリマを追加） |
| `bartersFor` / `craftsFor` | 生の barters / crafts から逆引きした `_buildAcquisitionIndex` の結果。クラフトチップのハイドアウト遷移も `station.id` でそのまま機能する |

## 関連 state

| state | 型 | 初期値 | 役割 |
|---|---|---|---|
| `armorClasses` | number[] | `[]` | クラスフィルタ（複数選択・OR・空 = 全て） |
| `armorClassOptions` | number[] (useMemo) | — | データにあるクラス（高い順）＝クラスフィルタのボタン |
| `armorZones` | string[] | `[]` | 部位フィルタ（`'front'`/`'back'`/`'left'`/`'right'`・OR・空 = 全て） |
| `armorBluntSort` | object | `{}` | クラスごとのブラント透過率ソート（`'asc'`/`'desc'`・未設定は耐久値順） |
| `armorByClass` | array (useMemo) | — | クラス・部位フィルタ適用後、クラスでグループ化・クラス内ソート済みのリスト（state はどれも保存しない＝リロードで初期値） |
