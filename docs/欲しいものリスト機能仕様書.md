# 欲しいものリスト（物々交換・クラフト）機能 — 機能詳細・実装仕様

> 対応ソース: `src/js/23-tab-barter.js`

> 最終更新: 2026-06-17

## 概要

トレーダーの物々交換（barter）とハイドアウトのクラフト（craft）から欲しいアイテムを選び、「狙っているものリスト」「お気に入り」に登録して必要素材と在庫を管理する。GETボタンで入手を活動ジャーナルに記録する。

> UIアイコンは全てSVG `<Icon>`。狙う=`target`、お気に入り=`heart`。

---

## データソース

GraphQL の `barters` と `crafts`。

```graphql
barters { trader { id name } level requiredItems { item count } rewardItems { item count } }
crafts  { station { id name } level duration requiredItems { item count } rewardItems { item count } }
```

### キー設計
- barterKey = `resultItemId::traderId::level`（`makeBarterKey`）
- craftKey も同様に結果アイテム＋施設＋レベルで一意化

---

## 状態管理

| state | 内容 | 保存先 |
|---|---|---|
| `wishlist` | 狙っている barter キー配列 | localStorage (`eft_tool_v2`) |
| `favorites` | お気に入り barter キー配列 | localStorage |
| `wishlistCrafts` | 狙っている craft キー配列 | localStorage |
| `wishlistOpen` / `favoritesOpen` | 各リストの開閉 | localStorage |

### 操作関数
```
addToWishlist(key) / removeFromWishlist(key)
addToFavorites(key) / removeFromFavorites(key)
addToWishlistCraft(key) / removeFromWishlistCraft(key)
```
いずれも重複追加を防止（既存ならそのまま）。

### 派生データ（useMemo）
- `allBarters`: `barters` を `{ key, resultItem, rewardCount, traderId, traderName, level, requiredItems }` に整形
- `wishlistBarters` / `favoritesBarters` / `wishlistCraftsBarters`: 各キー配列を実体に解決

---

## 表示構成

```
欲しいものサマリー（BarterSummaryBlock × 2: 狙う / お気に入り）
  └ 登録分の必要素材を集計し、在庫充足度を表示

狙っているものリスト（開閉・BarterCard / CraftCard）
お気に入りリスト（開閉・BarterCard）

候補一覧（全 barter / craft から検索して追加）
```

### コンポーネント
| コンポーネント | 役割 |
|---|---|
| `BarterSummaryBlock` | リスト全体の必要素材集計・充足度サマリー |
| `BarterCard` | 1物々交換カード（素材・在庫 `StashControl`・GET・お気に入り/削除） |
| `CraftCard` | 1クラフトカード（素材・在庫・所要時間・GET・施設レベル要件） |

### カード操作
- 在庫: `StashControl`（`+`/`−` または数値入力・`updateStash`）
- お気に入り追加/解除、リストから削除
- **GET**: 入手記録ボタン

---

## GET → 活動ジャーナル連携

GETボタン押下で `addJournalGet` を呼び、当日の入手記録に追記。

```
barter GET : addJournalGet(`{結果アイテム名}{ ×n }`, 'barter')
craft  GET : addJournalGet(`{結果アイテム名}{ ×n }`, 'craft')
```
