# 日誌機能仕様書（活動ジャーナル）

> 対応ソース: `src/js/27-tab-journal.js`

> 最終更新: 2026-06-17

## 概要

日々の活動（タスク完了数・アイテム入手・施設アップグレード）を記録し、日次グラフ・連続日数（ストリーク）・月間/累計統計で可視化する。多くの記録はアプリ内操作から**自動追記**される。

> UIアイコンは全てSVG `<Icon>`。

---

## データ構造（localStorage: `eft_journal_v1`）

```json
{
  "2026-06-17": {
    "tasks": 3,
    "memo": "今日の一言",
    "completedTasks": ["タスク名", ...],
    "gets": [
      { "name": "ADAR 2-15", "type": "barter",  "time": "14:30" },
      { "name": "GPU",        "type": "craft",   "time": "15:00" },
      { "name": "Medstation Lv2", "type": "hideout", "time": "16:00" }
    ],
    "wipe": false
  }
}
```

日付キーは `YYYY-MM-DD`（`toISOString().slice(0,10)`）。

### 入手種別 type → Icon

| type | Icon name | 意味 |
|---|---|---|
| （tasks フィールド） | `circle-check` | タスク完了 |
| `barter` | `shopping-cart` | 物々交換で入手 |
| `craft` | `tool` | ハイドアウトで作成 |
| `hideout` | `home` | 施設アップグレード |

---

## 状態管理

| state | 内容 |
|---|---|
| `journalLog` | 全日次記録（上記構造）。`JOURNAL_KEY` に保存 |
| `journalDraft` | 今日の入力途中（tasks / memo） |
| `journalDays` | グラフ表示日数 |

---

## 自動記録トリガー

| 操作 | 記録 |
|---|---|
| タスク検索タブで完了ボタン（`toggleComplete`） | 当日 `tasks` を新規完了数ぶん加算 |
| 欲しいものリストの barter GET | `addJournalGet(name, 'barter')` |
| 欲しいものリストの craft GET | `addJournalGet(name, 'craft')` |
| 設定タブの施設レベル「＋」 | `addJournalGet('{施設} Lv{n}', 'hideout')` |

`addJournalGet(itemName, type)` は当日エントリの `gets` に `{ name, type, time }` を追記（`time` は現在時刻）。

---

## 統計・集計

タブ描画時に `journalLog` から算出。

| 指標 | 算出 |
|---|---|
| ストリーク | 今日から遡り「`tasks + gets` > 0」が連続する日数（最大365日走査） |
| 今月タスク / 入手 | 当月キーの `tasks` / `gets.length` 合計 |
| 累計タスク / 入手 | 全エントリ合計 |
| 最高活動日 | `tasks + gets.length` が最大の日 |

### 日次グラフ
`journalDays` 日ぶんの `tasks + gets` を棒グラフ表示（`maxVal` で正規化）。

---

## 今日の記録フォーム

- タスク完了数: `−` / 数値入力 / `＋`（`journalDraft.tasks`）
- メモ入力
- 入手記録の一覧表示・編集（種別アイコン付き）

---

## エクスポート / インポート

JSONで書き出し・読み込み。インポート時は**既存データとマージ**（`✅ N件の記録をインポートしました` 等のネイティブダイアログ）。形式不正時はエラーダイアログ。
