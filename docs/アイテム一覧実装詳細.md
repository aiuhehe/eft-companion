## 1. 概要

`eft-tool.html` の「🔍 アイテム一覧」タブに含まれる3つのサブ機能の仕様と実装を記述する。

```
🔍 アイテム一覧
├── 損益計算 — カテゴリ別TOP3（トグル折り畳み）
├── ピン止め比較（トグル折り畳み）
├── ウォッチボード（登録アイテムの価格推移を常時表示・アイテム検索の上）
└── アイテム検索（常時表示・メイン機能）
```

## 3. 派生データ（useMemo）

### 3-1. filteredItems

```js
const filteredItems = useMemo(() => {
  let items = apiData.items;

  // 検索フィルター（スペース区切りトークンのAND検索 / 日本語名 or shortName）
  if (searchQuery) {
    const tokens = searchQuery.toLowerCase().split(/\s+/).filter(Boolean);
    items = items.filter(i => {
      const name = i.name?.toLowerCase() || '';
      const sn = i.shortName?.toLowerCase() || '';
      return tokens.every(t => name.includes(t) || sn.includes(t));
    });
  }

  // 取引可能フィルター
  if (onlyTradeable) {
    items = items.filter(i => {
      return i.buyFor?.some(b => {
        const tid = b.vendor?.trader?.id;
        if (!tid) return false;
        const st = traderStatus[tid] || { ll: 1 };
        const reqLL = b.vendor?.minTraderLevel || 1;
        const reqPL = apiData.traders.find(t => t.id === tid)
          ?.levels?.find(l => l.level === reqLL)?.requiredPlayerLevel || 0;
        return st.ll >= reqLL && playerLevel >= reqPL;
      });
    });
  }

  // 在庫フィルター
  if (onlyInStock) {
    items = items.filter(i => parseInt(stash[i.id] || 0) > 0);
  }

  return items.slice(0, 200); // 最大200件まで
}, [apiData.items, searchQuery, onlyTradeable, onlyInStock, stash, traderStatus, playerLevel, apiData.traders]);
```

**ポイント:**
- 検索はスペース（半角・全角どちらも `\s` で吸収）区切りの**トークンAND検索**。各トークンが `name` か `shortName` のいずれかに部分一致すれば対象。`M18 スモークグレネード` のような「型番＋種別」の組み合わせや全角スペース混在でもヒットする
- `onlyTradeable` はプレイヤーレベルとトレーダーLLの両方を考慮して判定
- `onlyInStock` は `stash[itemId]` が 1 以上かどうかで判定。`stash` を依存配列に含めているため、在庫増減と同時にリアルタイムで反映される
- 結果は最大200件に制限（パフォーマンス対策）

### 3-2. itemCategories（損益計算用）

```js
const itemCategories = useMemo(() => {
  const set = new Set();
  apiData.items.forEach(item => {
    // 購入・売却の両方が可能なアイテムのカテゴリのみ収集
    const hasBuy = profitBuyTrader
      ? (item.buyFor || []).some(b => b.vendor?.trader?.id === profitBuyTrader)
      : (item.buyFor || []).some(b => b.vendor?.trader?.id);
    const hasSell = profitSellTrader
      ? (item.sellFor || []).some(s => s.vendor?.trader?.id === profitSellTrader)
      : (item.sellFor || []).some(s => s.vendor?.trader?.id);
    if (hasBuy && hasSell) {
      (item.categories || []).forEach(c => set.add(c.name));
    }
  });
  return Array.from(set).sort();
}, [apiData.items, profitBuyTrader, profitSellTrader]);
```

**ポイント:** トレーダー指定がある場合は、そのトレーダーで実際に取引可能なアイテムのカテゴリのみを返す。カテゴリボタンが変わるのはこのため。

### 3-3. profitTop3（損益計算）

```js
const profitTop3 = useMemo(() => {
  if (apiData.items.length === 0) return [];
  const results = [];
  for (const item of apiData.items) {
    // カテゴリ絞り込み（複数選択はOR条件）
    if (profitCategoryFilter.length > 0) {
      const cats = (item.categories || []).map(c => c.name);
      if (!profitCategoryFilter.some(f => cats.includes(f))) continue;
    }
    // 売却候補（トレーダーへの売却のみ）
    let traderSells = (item.sellFor || []).filter(s => s.vendor?.trader?.id);
    if (profitSellTrader) traderSells = traderSells.filter(s => s.vendor.trader.id === profitSellTrader);
    if (traderSells.length === 0) continue;
    const bestSellRUB = Math.max(...traderSells.map(s => s.priceRUB));
    const bestSell = traderSells.find(s => s.priceRUB === bestSellRUB);

    // 購入候補（トレーダーからの購入のみ）
    let traderBuys = (item.buyFor || []).filter(b => b.vendor?.trader?.id);
    if (profitBuyTrader) traderBuys = traderBuys.filter(b => b.vendor.trader.id === profitBuyTrader);
    if (traderBuys.length === 0) continue;
    const bestBuyRUB = Math.min(...traderBuys.map(b => b.priceRUB));
    const bestBuy = traderBuys.find(b => b.priceRUB === bestBuyRUB);

    const loss = bestBuyRUB - bestSellRUB; // 正=損失、負=利益
    results.push({ item, bestBuy, bestBuyRUB, bestSell, bestSellRUB, loss });
  }
  results.sort((a, b) => a.loss - b.loss); // 損失が少ない（利益が大きい）順
  return results.slice(0, 3);
}, [apiData.items, profitCategoryFilter, profitBuyTrader, profitSellTrader]);
```

**損益の定義:** `loss = 購入価格(RUB) - 売却価格(RUB)`
- `loss < 0` → 利益（売却の方が高い）
- `loss > 0` → 損失（購入の方が高い）

## 4. コールバック関数

### 4-1. pinItem / unpinItem / updatePinQty

```js
const pinItem = useCallback((item) => {
  setPinnedItems(prev => {
    if (prev.find(p => p.itemId === item.id)) return prev; // 重複防止
    if (prev.length >= 6) return prev;                      // 上限6件
    return [...prev, { itemId: item.id, qty: 1, item }];
  });
}, []);

const unpinItem = useCallback((itemId) => {
  setPinnedItems(prev => prev.filter(p => p.itemId !== itemId));
}, []);

const updatePinQty = useCallback((itemId, delta) => {
  setPinnedItems(prev => prev.map(p =>
    p.itemId === itemId ? { ...p, qty: Math.max(1, p.qty + delta) } : p
  ));
}, []);
```

### 4-2. 目標金額から個数を自動計算（useEffect）

```js
useEffect(() => {
  const amount = parseShorthand(pinTargetAmount); // "2M" → 2000000
  if (!pinTargetTrader || !amount || amount <= 0) return;
  setPinnedItems(prev => prev.map(p => {
    const traderBuys  = (p.item.buyFor  || []).filter(b => b.vendor?.trader?.id);
    const traderSells = (p.item.sellFor || []).filter(s => s.vendor?.trader?.id);
    const bestBuyRUB  = traderBuys.length  > 0 ? Math.min(...traderBuys.map(b => b.priceRUB))  : 0;
    const bestBuy     = traderBuys.find(b => b.priceRUB === bestBuyRUB);
    const bestSellRUB = traderSells.length > 0 ? Math.max(...traderSells.map(s => s.priceRUB)) : 0;
    const bestSell    = traderSells.find(s => s.priceRUB === bestSellRUB);
    let unitPrice = 0;
    if (bestBuy?.vendor?.trader?.id  === pinTargetTrader) unitPrice += bestBuyRUB;
    if (bestSell?.vendor?.trader?.id === pinTargetTrader) unitPrice += bestSellRUB;
    if (unitPrice <= 0) return p;
    const qty = Math.ceil(amount / unitPrice);
    return { ...p, qty: Math.max(1, qty) };
  }));
}, [pinTargetTrader, pinTargetAmount]);
```

**動作:** 指定トレーダーの「購入価格+売却価格」を単価として、`⌈目標金額 / 単価⌉` 個に自動更新する。

### 4-3. loadItemHistory / toggleItemHistory（価格履歴）

```js
const loadItemHistory = useCallback((itemId) => {
  if (historyReqRef.current.has(itemId)) return;          // 取得済み/取得中なら何もしない
  historyReqRef.current.add(itemId);
  const gm = gameMode === 'pve' ? 'pve' : 'regular';
  setHistoryCache(prev => ({ ...prev, [itemId]: { loading: true, error: null, points: null } }));
  fetchGraphQL(`{ historicalItemPrices(id: "${itemId}", gameMode: ${gm}) { price priceMin timestamp } }`)
    .then(data => { /* data.historicalItemPrices を points 化・t昇順ソートして cache へ */ })
    .catch(e => { historyReqRef.current.delete(itemId); /* error を cache へ・再取得可 */ });
}, [gameMode]);

const toggleItemHistory = useCallback((itemId) => {
  setHistoryOpenId(prev => (prev === itemId ? null : itemId)); // 同じIDなら閉じる
  loadItemHistory(itemId);                                     // 取得（キャッシュ済みなら即return）
}, [loadItemHistory]);

// ゲームモード(PvP/PvE)切替時は価格が変わるため履歴キャッシュを破棄
useEffect(() => { historyReqRef.current = new Set(); setHistoryCache({}); setHistoryOpenId(null); }, [gameMode]);
```

- **履歴はアイテム一覧の本体クエリ（`limit:100000`・約5000件）には含めず、アイテム行クリック時にアイテム単位でオンデマンド取得**する（一括取得は重いため）。
- **`historicalItemPrices(id, gameMode)`** を使用。返るのは**最大30日分**（データのある範囲。検証時点で約7日・67点）。`item.historicalPrices`（約2日のみ）ではなくこちらを使う。
- 一部アイテム（フリマ取引不可など）は0件。`gameMode` 切替時はキャッシュを破棄して取り直す。

## 5. APIクエリフィールド（アイテム一覧関連）

```graphql
items(gameMode: $gameMode, lang: ja, limit: 100000) {  // 全アイテム取得（総数が2000を超えたため引き上げ。2026-06-27時点 約5043件）
  id
  name
  shortName
  iconLink
  categories { name }
  sellFor {
    vendor { ... on TraderOffer { trader { id name } minTraderLevel } }
    priceRUB
  }
  buyFor {
    vendor { ... on TraderOffer { trader { id name } minTraderLevel } }
    priceRUB
    currency
    price
  }
  low24hPrice   # フリマ最安値（過去24時間）
  high24hPrice  # フリマ最高値（過去24時間）
  avg24hPrice   # フリマ平均値（過去24時間）
}
```

**フリマ価格の注意点:**
- 全リージョン（EU・NA・RU・Asia等）の集計データ
- リアルタイムではなく数時間のラグがある
- PvE / PvP でゲームモードを正しく設定しないと価格が異なる
- ゲーム内の特定サーバーの価格とは一致しない場合がある → UIにツールチップで案内

**価格履歴クエリ（オンデマンド・本体クエリとは別）:**

```graphql
{ historicalItemPrices(id: "<itemId>", gameMode: regular) { price priceMin timestamp } }
```

- アイテム行クリック時にアイテム単位で取得（`loadItemHistory`）。本体の `items(...)` には含めない。
- `price` = 平均, `priceMin` = 最安, `timestamp` = ms（文字列で返るため `Number()` 化）。
- **`historicalItemPrices` は最大30日分**を返す（データのある範囲。検証時点で約7日・67点）。
  - 参考: `item.historicalPrices` は約2日分しか返さない（APIが `historicalItemPrices` の使用を警告で推奨）。本ツールでは使わない。

### 6-2b. ウォッチボード（アイテム検索の上・常時表示）

```
[Icon: eye] ウォッチボード（N）          [chevron]  ← タイトルクリックで開閉
├── (watchBoardOpen === false なら中身を隠す)
├── [✓] 2列で表示（半分の幅で2個ずつ並べる）   ← watchBoardTwoCol
├── (登録0件) → 「アイテム検索結果の [eye] ボタンで登録すると、ここに価格推移が常時表示されます。」
└── 登録アイテムごとに watch-card（grid: 1列 or 2列）
    ├── watch-card-head: アイコン + 名前 + shortName + フリマ最安/平均/最高(24h) + 外すボタン [Icon: x]
    └── FleaHistoryChart（常時展開・トグル不要）
```

- アイテム検索結果の各行の [eye] ボタンで登録/解除（`toggleWatchBoard`）。`watchBoardIds` に保存され**リロード後も維持**。
- **タイトルクリックでセクション開閉**（`watchBoardOpen`・chevron で状態表示）。**「2列で表示」チェックボックス**（`watchBoardTwoCol`）でカード並びを `display:grid` の `1fr` / `1fr 1fr` で切替（2列時はチャートが半分幅）。両設定とも永続化。
- アイテム一覧タブを開くと登録アイテムの履歴を自動取得（検索不要で価格推移が並ぶ）。取得に数秒かかる間は各カードがスピナー表示。
- **「APIデータ取得」で最新化される**：カード上部の現在価格は `apiData.items` 由来なので即更新。チャート（`historicalItemPrices`）も、`loadAPIData` 成功時に**重複防止ref（`historyReqRef`）だけリセット**し、`lastLoaded` の変化で自動取得 useEffect が再実行されて再取得→差し替わる。**`historyCache` は空にしない**（既存グラフを残したまま差し替えるのでチラつかない）。`loadItemHistory` も「既存points があればローディング表示にせず温存」するため、再取得中もグラフが消えない。
  - 補足: `gameMode`（PvP/PvE）切替時は価格自体が別物なので、別の useEffect が `historyCache` を空にして取り直す。
- `apiData.items` 未取得のIDは「アイテムデータ未取得」プレースホルダ＋外すボタンを表示。
- CSS: `.watch-card`（カード）／`.watch-card-head`（ヘッダー行）。

## 7. StashControl コンポーネント

アイテムの在庫数を表示・編集する共通コンポーネント。アイテム一覧のほか、バータータブ・クラフトタブ・ハイドアウトタブでも共用している。

```jsx
const StashControl = ({ itemId, have, onUpdate }) => (
  <span style={{ display: 'inline-flex', alignItems: 'center', gap: 2 }}>
    <button onClick={() => onUpdate(itemId, -1)} disabled={have <= 0}>−</button>
    <span style={{ minWidth: 24, textAlign: 'center', ... }}>{have}</span>
    <button onClick={() => onUpdate(itemId, 1)}>＋</button>
  </span>
);
```

| prop | 型 | 説明 |
|------|----|------|
| `itemId` | string | アイテムID（`stash` オブジェクトのキー） |
| `have` | number | 現在の在庫数（親が `stash[item.id]` を渡す） |
| `onUpdate` | (itemId, delta) => void | `updateStash` を渡す。delta は +1 or -1 |

**数値表示の色分け:**
- `have > 0` → `var(--accent)`（黄色）・太字
- `have === 0` → `var(--text-dim)`（グレー）・通常ウェイト

`updateStash` の実装:

```js
const updateStash = (itemId, delta) => {
  setStash(prev => {
    const next = { ...prev };
    const cur = parseInt(next[itemId] || 0);
    const nv = Math.max(0, cur + delta);
    if (nv === 0) delete next[itemId];
    else next[itemId] = nv;
    return next;
  });
};
```

- 0 未満にはならない（`Math.max(0, ...)`）
- 在庫が 0 になったキーは `stash` から削除してオブジェクトを軽量に保つ
