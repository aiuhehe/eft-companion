# マップ機能仕様書

## 概要

タブID: `maps` / アイコン: `map` / ラベル: マップ

タスク目標（objective）をマップ画像上の座標にピン登録・管理するタブ。出撃準備タブの地図可視化（`MapPinVisual`）のデータ元となる。

---

## データ構造

### `eft_maps_v1`（グローバルキー・全モード共通）

```json
{
  "Customs": { "file": "Customs.png", "width": 2048, "height": 2048 }
}
```

キーはマップ名（`RAID_MAP_IMAGE_FILES` と同じ英語表記）。`width`/`height` は初回アクセス時に `Image.naturalWidth/Height` で自動取得して保存。

### `eft_task_pins_v1`（グローバルキー・全モード共通）

```json
[{
  "id": "pin_<objectiveId>_<timestamp>",
  "mapName": "Customs",
  "taskId": "<taskId>",
  "objectiveId": "<objectiveId>",
  "x": 1220,
  "y": 830,
  "memo": "404号室の机の上",
  "requiredItems": [{ "id": "<itemId>", "name": "RB-BK Key", "shortName": "RB-BK", "iconLink": "..." }],
  "memoImages": [{ "id": "pimg_<ts>_<rand>", "name": "画像1", "dataUrl": "data:image/jpeg;base64,..." }]
}]
```

1レコード＝1ピン座標。**同じ objectiveId に複数ピン登録可能**（スポーン地点が複数ある目標に対応）。`id` は `pin_${objectiveId}_${Date.now()}` 形式で一意。`x`/`y` は画像の実ピクセル座標（表示は `left: x/width*100%`、`top: y/height*100%`）。
`memo`（任意）: 場所の詳細テキスト（例: 「404号室の机」）。`requiredItems`（任意）: 必要な鍵・タスク品などの配列（`apiData.items` または登録タスク品から検索して追加）。
`memoImages`（任意・2026-10-06追加）: 詳細位置画像（スクショ）の配列。`name` は省略名（既定「画像N」・編集可）、`dataUrl` は `imageFileToPhotoDataUrl` で長辺1280px・JPEG品質0.8に縮小したもの（localStorage 容量対策）。
登録タスク品の要素は `{ id: "citem_...", name, shortName, custom: true }`（**画像 dataURL は複製せず id 参照のみ**）。表示時に `resolvePinItem` で `eft_custom_items_v1` の最新の名前・画像に解決する。

### `eft_custom_items_v1`（グローバルキー・全モード共通）

アイテム一覧（API）に無いタスク品（設置用のクエストアイテム等）をユーザーが名前＋画像で登録したもの。

```json
[{ "id": "citem_<timestamp>", "name": "Secure Flash drive", "shortName": "Flash", "iconLink": "data:image/png;base64,..." }]
```

`iconLink` は登録時に `imageFileToIconDataUrl`（`04-helpers.js`）で**長辺最大128pxに縮小した PNG dataURL**（localStorage 容量対策）。画像なしも可（空文字）。

### マップ画像の差し替え（利用者ごと・2026-10-30）

利用者が自分の画像（メモ書き入りのマップ等）に差し替えられる。差し替えはブラウザごと（IndexedDB）で、`maps/` のファイル自体は変更しない。

- **保存先**: IndexedDB `eft_media` / ストア `mapOverrides`（key = マップ名、value = 画像Blob）。localStorage の容量（約5MB）を圧迫しないため IndexedDB を使う。ヘルパーは `03-storage.js` の `mediaGetAllMapOverrides` / `mediaPutMapOverride` / `mediaDeleteMapOverride` / `mediaClearMapOverrides`。
- **UI**: マップ表示エリアの直下・右寄せの控えめなテキストリンク（`.map-image-replace` / `.map-image-replace-link`）。
  - 通常時: 「画像を差し替え」（クリックで画像ファイル選択）
  - 差し替え中: 「差し替え画像を表示中 元の画像に戻す / 画像を差し替え」
  - 「未登録」表示中（`mapsLoadFailed[selected]`）はこのリンク行を出さず、案内内の目立つボタン（`btn-yellow`「画像を差し替え」）に置き換える。元画像なしでも差し替え画像で運用できる。
  - ファイル選択の処理はリンク・ボタン共通の `onReplaceFileChange`（成功時 `mapsLoadFailed[selected]` を解除）。
- **未登録時の案内**: マップタブは「{マップ名} のマップ画像が未登録です。」＋ REƎMR EFTMAPS へのリンク・登録手順・「Maps by REƎMR — CC BY-NC-SA 4.0」＋「画像を差し替え」ボタン・「再試行」ボタンを表示。メタ（ピン座標の基準）が既にあるマップでは「登録済みピンの位置はそのまま引き継がれます。」を添える。出撃準備タブの `MapPinVisual` も「マップ画像が未登録です」＋入手先リンクを表示。
- **画像の読み込み失敗検知（Issue #1・2026-10-30）**: `eft_maps_v1` にメタが既にある（＝ローカル版のバックアップを公開版に復元した等）と `ensureMapImageRegistered` は画像を読みに行かないため、`maps/<file>` が 404 でも気づけなかった。表示用 `<img>` の `onError` で検知する。
  - マップタブ: 差し替え画像が無いマップで `<img>` の読み込みに失敗したら `mapsLoadFailed[selected] = true` にして「未登録」案内へ切り替える。**メタは消さない**ので、差し替え後も既存ピンは元の位置に出る。マップ切替・再試行で `false` に戻し再読込する。
  - 出撃準備タブ（`MapPinVisual`）: 失敗した URL を `failedSrc` に覚え、現在の `src` と一致する間は未登録案内を表示（差し替え画像が入って `src` が変われば自動で再表示を試みる）。
- **ピン座標との関係**: ピン座標の基準（`eft_maps_v1` の `width`/`height`）は**変更しない**。表示は％配置なので、同じ範囲を写した画像なら解像度が違ってもピン位置は一致する。縦横比が元画像と2%以上違う場合はネイティブ `confirm` で警告（ピンがずれる可能性）。基準が未登録のマップ（元画像なし）は差し替え画像のサイズで登録する。
- **表示**: マップタブ・出撃準備タブ（`MapPinVisual`）とも `getMapImageSrc(mapName, meta)` で URL を決定（差し替え objectURL 優先 → `maps/<file>`）。
- **起動時**: IndexedDB から読み込んで objectURL 化（`mapImageOverrides` state）。読込完了時、「見つかりません」状態のマップは差し替え画像で再登録を試みる（`11-app-effects.js`）。`ensureMapImageRegistered` も `maps/` 読込失敗時に差し替え画像へフォールバックする。
- **バックアップ**: 設定タブの全データバックアップに `media.mapOverrides`（dataURL）として含まれ、復元時に IndexedDB へ書き戻される（[ステータス・設定機能仕様書.md](ステータス・設定機能仕様書.md)）。

| state | 型 | 説明 |
|---|---|---|
| `mapImages` | `{ [mapName]: { file, width, height } }` | マップ画像メタデータ。localStorage `eft_maps_v1` から初期化 |
| `taskPins` | `Array<{ id, mapName, taskId, objectiveId, x, y, memo?, requiredItems?, memoImages? }>` | ピン一覧。localStorage `eft_task_pins_v1` から初期化 |
| `mapsSelectedMap` | `string \| null` | マップタブで選択中のマップ名 |
| `mapsPlacingObjective` | `{ taskId, objectiveId } \| null` | 目標先行フロー：地図クリック待ち中の目標 |
| `mapsRepositioningPinId` | `string \| null` | 再配置中のピン ID |
| `mapsPendingPinCoords` | `{ x, y } \| null` | 地図先行フロー：仮ピン座標 |
| `mapsPinEditId` | `string \| null` | 編集中のピン ID（ペンシルアイコンでトグル） |
| `mapsPinMemoInput` | `string` | メモ入力欄の値（編集中ピン） |
| `mapsPinItemSearch` | `string` | アイテム追加検索の入力値 |
| `pinImageViewer` | `{ id, name, dataUrl } \| null` | 拡大表示中の詳細位置画像（`90-render-close.js` の `.pin-img-viewer` オーバーレイで全タブ共通表示・クリックで閉じる） |
| `customItems` | `Array<{ id, name, shortName, iconLink }>` | 登録タスク品。localStorage `eft_custom_items_v1` から初期化 |
| `mapsItemMgrOpen` | `boolean` | 「登録タスク品」セクションの開閉 |
| `mapsItemForm` | `{ editId, name, shortName, iconLink, attachPinId, error } \| null` | タスク品 登録/編集モーダルの入力状態。`attachPinId` があれば新規登録後そのピンの必要アイテムに自動追加 |

### 関数

| 関数 | 説明 |
|---|---|
| `ensureMapImageRegistered(mapName)` | mapName が未登録なら `maps/<file>` を読み込んで自動登録（Promise、失敗時は null）。`maps/` が無ければ差し替え画像で登録 |
| `getMapImageSrc(mapName, meta)` | 表示用URL（差し替え画像の objectURL を優先、なければ `maps/<file>`） |
| `replaceMapImage(mapName, file)` | 差し替え画像を IndexedDB に保存して表示を切替（縦横比チェック付き）。成功時 true |
| `resetMapImage(mapName)` | 差し替えを解除して元画像に戻す |
| `addTaskPin(mapName, taskId, objectiveId, x, y)` | 新規ピン追加（同 objectiveId に複数追加可・タイムスタンプ付き一意ID） |
| `updateTaskPinPosition(pinId, x, y)` | 既存ピンの座標更新（再配置・ステージング確定） |
| `removeTaskPin(pinId)` | ピン削除（指定 ID のみ削除） |
| `updatePinMeta(pinId, updates)` | ピンの `memo`・`requiredItems`・`memoImages` を更新（`{ ...pin, ...updates }` でマージ）。`updates` に `(pin) => object` も渡せる（連続貼り付け時の競合回避）。localStorage 保存失敗（容量不足）時は alert して変更を破棄 |
| `addCustomItem({ name, shortName, iconLink })` | タスク品を新規登録し、作成したオブジェクトを返す |
| `updateCustomItem(id, updates)` | タスク品の名前・短縮名・画像を更新（ピン側は id 参照なので自動で反映） |
| `removeCustomItem(id)` | タスク品を削除し、全ピンの `requiredItems` からも外す |

## UI 構成（`34-tab-maps.js`）

### 1. マップ選択バー

`RAID_MAP_IMAGE_FILES` の全13マップを横並びタブ表示（`.mapreg-tab`）。

- アクティブ: `.is-active`（アクセントカラー枠）
- 画像登録済み: `.is-registered`（緑枠）+ `circle-check` アイコン

### 2. マップ表示エリア

選択マップの画像（`maps/<file>`）を表示。

- **画像未読み込み**: `ensureMapImageRegistered` を呼び出し読み込み中表示。失敗時はエラーメッセージ＋再試行ボタン
- **画像読み込み済み**: 画像 + 登録済みピンマーカー（`MapPinMarker`）+ 仮ピン（逆順フロー中）

#### 操作モード案内バー（画像上部にオーバーレイ）

モードが `mapsPlacingObjective`/`mapsRepositioningPinId`/`mapsPendingPinCoords` のいずれかにセットされている間、画像上部に案内テキスト＋キャンセルボタンを表示。地図カーソルは `crosshair` になる。

#### 地図クリック時の分岐

1. `mapsPlacingObjective` セット中 → `addOrUpdateTaskPin` で確定してクリア
2. `mapsRepositioningPinId` セット中 → 該当ピンの座標を更新してクリア
3. どちらも無し → `mapsPendingPinCoords` に仮座標を保存（逆順フロー開始）

### 3. ステージングモード（ピン位置微調整）

`mapsPlacingObjective` がセットされた状態で地図をクリックすると `mapsPendingPinCoords` に仮座標を保存する（`isStaging = isPlacing && isPendingCoord`）。

- 地図上に黄色の仮ピンが表示され、クリックするたびに位置が移動する
- 操作ガイドバーに「この位置で確定」ボタン → `confirmPlacement()` → `addTaskPin` で確定、両state クリア
- 「キャンセル」ボタンで全state クリア

### 4. 逆順フロー（地図クリック先行）

`mapsPlacingObjective` なし・`mapsRepositioningPinId` なしで地図をクリックすると `mapsPendingPinCoords` に仮座標を保存（`isReverseFlow = isPendingCoord && !isPlacing`）。

- 地図上に白半透明の仮ピンを表示
- ガイドバー下に目標絞り込み検索ボックスを表示（ピン未登録目標のみ対象）
- 候補を選択 → `addTaskPin` で確定して `mapsPendingPinCoords` クリア

### 5. ピン未登録リスト / ピン登録済みリスト（横並び）

2列横並びレイアウト（`display: flex; gap: 8px`）。**進行中（`pinnedTaskIds` に含まれる）かつ未完了のタスクのみ表示**（完了済み・未受注タスクは除外）。

**ピン未登録列 / ピン登録済み列（共通）:**
- どちらもカテゴリ別セクションに分けて表示（`CAT_ORDER`: collect → bring → place → kill → extract → locate の順）
- 存在するカテゴリのみセクションを表示。セクションヘッダーはカテゴリカラーのアイコン＋日本語ラベル＋件数

| カテゴリキー | 表示ラベル |
|---|---|
| collect | 収集（FIR） |
| bring | 持込・納品 |
| place | 設置・マーキング |
| kill | 倒すもの |
| extract | 脱出 |
| locate | 調査・特定 |

**ピン未登録列:**
- 各行: カテゴリアイコン・目標名・×N・タスク名ボタン（クリックでポップアップ表示）・トレーダーバッジ・`obj.description`
- 「ピンを設置」ボタン → `mapsPlacingObjective` にセットしてステージングモードへ

**ピン登録済み列:**
- 各行: 同上の情報 + 「ピンを追加」ボタン（追加スポーン地点登録）
- 同 objectiveId のピンをスポーン番号付きで複数行表示（「スポーン1」「スポーン2」…）
- 各スポーン行: 「再配置」ボタン + 鉛筆アイコン（メモ・アイテム編集トグル）+ 削除ボタン
- メモ/必要アイテム/詳細位置画像が登録済みの場合、非編集時もスポーン行の下に表示（画像は省略名チップ `PinImageChips`・クリックで拡大）
- 鉛筆アイコンクリックで編集フォームを展開：
  - メモテキスト入力（blur 時に `updatePinMeta` で自動保存）
  - **詳細位置画像**: 編集フォーム内にフォーカスがある状態（メモ欄 or 「詳細位置画像: クリックして Ctrl+V で貼り付け」ゾーン `.pin-img-paste-zone`）で **Ctrl+V** するとクリップボードの画像を `addPinImage` で追加（ファイル選択ダイアログは無し・ゾーンへのドロップも可）。省略名「画像N」で自動命名され、サムネ横の入力欄で省略名を変更可（blur/Enter で保存）、×で削除、サムネクリックで拡大
  - 必要アイテム一覧（×ボタンで削除）
  - アイテム追加検索（2文字以上で絞り込み。**登録タスク品（「タスク品」バッジ）を先頭**に、続いて `apiData.items` 最大10件・クリックで追加）
  - 検索ドロップダウン末尾に「「〇〇」をタスク品として登録（画像付き）」→ 入力値を名前に入れた登録モーダルを開き、保存するとそのピンに自動追加
  - 検索欄ラベル右の「タスク品を登録」ボタンでも同モーダルを開ける（同じく保存後に自動追加）
  - 検索欄が空のときは、未追加の登録タスク品をクイック追加チップ（破線枠）で表示

### 5-2. 登録タスク品セクション（タブ下部・折りたたみ）

「登録タスク品 (N件)」ヘッダーをクリックで開閉。右の「新規登録」ボタンで登録モーダルを開く。

- 各カード: 画像（40px）・名前・短縮名・紐づいているピン数とマップ名
- 鉛筆ボタン: 編集モーダル（名前・短縮名・画像の変更）
- ゴミ箱ボタン: `confirm` 後に削除（紐づいたピンからも外れる）

### 5-3. タスク品 登録/編集モーダル

- 画像枠（96px）: **クリックでファイル選択／画像ファイルのドロップ／Ctrl+V でクリップボード画像の貼り付け**（スクショを切り取ってそのまま貼れる）。読み込み時に128pxへ縮小
  - Ctrl+V は **モーダル表示中ならフォーカス位置に関係なく有効**（`13-app-memos.js` の window `paste` リスナーが `mapsItemForm` 表示中はこのモーダルの画像に振り分ける）。マップタブではモーダル外の Ctrl+V 画像を OCR に回さない。個別処理で `preventDefault` 済みの貼り付け（ピン詳細位置画像）はスキップ
- アイテム名（必須）・短縮名（任意。チップにはこちらを優先表示）
- 「画像を外す」・Enter キーで保存
- 必要アイテムチップは、API アイテムが黄系（`--warn-*`）、登録タスク品が青系（`--info-*`）で色分け（`PinItemChip`）

### 6. タスク詳細ポップアップ（マップタブ版）

タスク名ボタンクリックで `mapsDetailTask` にセットして表示。タスク検索タブへ遷移しない。

- 目標ごとに「現在選択中マップのピン操作」エリアを表示（`isOnCurrentMap` 判定）
- 既存ピン数とスポーン番号別の「再配置」ボタン
- 「ピンを設置」/「ピンを追加」ボタン → ポップアップを閉じてステージングモードへ
- 「進行中から外す」/「進行中に追加」トグルボタン（`pinnedTaskIds` 操作）

## 共通コンポーネント（`14-app-components.js`）

### `PinItemChip` / `resolvePinItem`

ピンの必要アイテムチップの共通描画（マップタブ・ピン吹き出し・`MapPinVisual` サイドパネル・出撃準備タブの目標行）。`resolvePinItem(item)` は `item.custom` のとき `customItems` から最新の名前・画像を引く。props: `item`、`size`（`'md'`/`'sm'`）、`onRemove`（指定時は×ボタン表示）。

### `MapPinMarker`

| prop | 型 | 説明 |
|---|---|---|
| `leftPct` | number | ピン水平位置（%） |
| `topPct` | number | ピン垂直位置（%） |
| `obj` | object | タスク目標オブジェクト |
| `task` | object | タスクオブジェクト |
| `cat` | string | カテゴリ（bring/collect/place/kill/extract/locate） |
| `pin` | object \| undefined | ピンデータ（`memo`・`requiredItems` 表示に使用） |
| `pinIndex` | number \| null | 複数ピンの番号（1始まり）。null のとき番号非表示 |
| `onRemove` | function \| undefined | 削除ハンドラ（未定義なら削除ボタン非表示） |
| `onReposition` | function \| undefined | 再配置ハンドラ（未定義なら再配置ボタン非表示） |

### `MapPinVisual` 追加 props（出撃準備タブ用）

| prop | 型 | 説明 |
|---|---|---|
| `onToggleCheck` | `(taskId, obj) => void` \| undefined | サイドパネル行クリック時のチェックトグル。渡すと行がクリッカブルになる |
| `isChecked` | `(taskId, obj) => boolean` \| undefined | チェック状態の参照関数 |

**クリックで吹き出しをトグル表示**（ホバー→クリック方式に変更済み）。吹き出し外クリック（document `mousedown`）で閉じる。吹き出しに `pin.memo`（テキスト）と `pin.requiredItems`（アイテムチップ）、`pin.memoImages`（省略名チップ・クリックで拡大）を表示。`onRemove`/`onReposition` が渡された場合はボタンも表示（出撃準備タブ側は渡さない・閲覧専用）。

### `MapPinVisual`

出撃準備タブに埋め込む読み取り専用ビュー。ピン0件の場合は `null` を返す（何も表示しない）。

**レイアウト（左右分割 + SVG接続線）**

```
┌──────────────────────────────┬───────────────────┐
│  マップ画像                    │  ① タスク名        │
│                               │    目標テキスト     │
│   ①   ②                    │──────────────────│
│                               │  ② タスク名        │
│         ③                   │    目標テキスト     │
└──────────────────────────────┴───────────────────┘
         SVGベジェ曲線で①②③と右パネルを接続
```

- **左**: `flex: 1` のマップ画像エリア。ピンは番号付き円形バッジ（`CAT_COLOR` 配色）に変更。ホバー時に白反転。
- **右**: 固定幅 188px のサイドパネル。ピンを縦位置順（Y座標昇順）にリスト表示。番号・タスク名・目標名・FIRバッジ・カテゴリアイコンを常時表示。`pin.memo`・`pin.requiredItems`・`pin.memoImages`（省略名チップ）がある場合は目標名の下に表示。出撃準備タブの目標行（`pinMetaBlock`）にも同じ省略名チップを表示。`onToggleCheck` が渡されている場合は行クリックでチェックをトグル（チェック済みは緑バッジ＋opacity 50%）。
- **SVG**: コンテナ全体に `position: absolute` で重ねた透明SVG。ピン中心から右パネル該当行中央へベジェ曲線（`C` コマンド）で接続。ホバー時は実線・太め、通常時は破線・半透明。
- **ホバー連動**: ピンまたは右パネル行をホバーすると対応する要素がハイライト（`highlighted` state）。

**hooks（`MapPinVisual` 内）**

| hook | 目的 |
|---|---|
| `useRef` × 3 | `containerRef`（外枠）・`imgRef`（img要素）・`itemRefs`（パネル各行） |
| `useState(lines)` | SVGパスの座標配列 |
| `useState(imgRev)` | 画像ロード完了を `useLayoutEffect` に伝えるカウンタ |
| `useState(highlighted)` | ホバー中のpin.id |
| `useMemo(pinsWithData)` | pins × objectivesHere のマージ |
| `useMemo(sortedPins)` | Y座標昇順ソート済み配列 |
| `useCallback(recalcLines)` | DOM測定 → `setLines` |
| `useLayoutEffect` | 描画後に `recalcLines` 実行・resize リスナー登録 |
