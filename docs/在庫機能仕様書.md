## 1. 概要

`eft-tool.html` にスタッシュスクリーンショットからアイテム在庫を一括登録するOCR機能を追加した。

**ユーザーフロー:**
1. 「📸 スクリーンショット登録」タブを開く
2. 画像をドロップ / クリック選択 / Ctrl+V 貼り付け
3. クロップ比率スライダーで読み取り範囲を調整
4. 「🔍 OCR解析実行」で解析
5. 認識結果を確認・修正（個数±、候補切替、補完候補から選択）
6. 「✅ 在庫に追加」で stash に一括反映

## 4. コンポーネント外に定義したユーティリティ関数

### 4-1. レーベンシュタイン距離

```js
const levenshtein = (a, b) => {
  const dp = Array.from({ length: a.length + 1 }, (_, i) => [i]);
  for (let j = 1; j <= b.length; j++) dp[0][j] = j;
  for (let i = 1; i <= a.length; i++)
    for (let j = 1; j <= b.length; j++)
      dp[i][j] = a[i-1] === b[j-1] ? dp[i-1][j-1]
        : 1 + Math.min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]);
  return dp[a.length][b.length];
};
```

OCR誤字（`Sguash` → `Squash`、`HosRod` → `HotRod` など）を吸収するために使用。

### 5-2. スコア計算関数（matchOcrText 内のローカル関数）

#### compareStrings（ベース比較）

```js
const compareStrings = (tLow, c) => {
  if (!c) return 0;
  if (c === tLow) return 1.0;
  // 前方一致ボーナス: "bat" が "battery" の先頭にマッチ → 短い方の割合 * 1.3
  if (c.startsWith(tLow)) return Math.min(1.0, (tLow.length / c.length) * 1.3);
  if (tLow.startsWith(c)) return Math.min(1.0, (c.length / tLow.length) * 1.3);
  // 部分一致
  if (c.includes(tLow) || tLow.includes(c))
    return Math.min(c.length, tLow.length) / Math.max(c.length, tLow.length);
  // レーベンシュタイン（最小長3）
  if (tLow.length >= 3 && c.length >= 3) {
    const dist = levenshtein(tLow, c);
    const maxLen = Math.max(tLow.length, c.length);
    const maxDist = maxLen >= 7 ? 3 : maxLen >= 5 ? 2 : 1;
    if (dist <= maxDist) return (1 - dist / maxLen) * 0.92;
  }
  return 0;
};
```

**スコアの種類:**

| 条件 | スコア式 | 例 |
|------|---------|-----|
| 完全一致 | 1.0 | `"squash"` = `"squash"` |
| 前方一致 | `min(1.0, short/long * 1.3)` | `"bat"` → `"battery"` |
| 部分一致 | `min/max` | `"cola"` in `"ratcola"` |
| レーベンシュタイン | `(1 - dist/maxLen) * 0.92` | `"sguash"` → `"squash"` (dist=1) |

**レーベンシュタイン許容距離:**

| 最大長 | 許容距離 |
|--------|---------|
| 3〜4文字 | 1文字差まで |
| 5〜6文字 | 2文字差まで |
| 7文字以上 | 3文字差まで |

#### calcScore（単語分割・ペア結合込み）

```js
const calcScore = (tLow, c) => {
  const direct = compareStrings(tLow, c);
  const words = c.split(/[\s\-_]+/).filter(w => w.length >= 2);
  let wordBest = 0;
  if (words.length > 1) {
    // 各単語単体（0.95倍ペナルティ）
    for (const w of words) {
      const s = compareStrings(tLow, w) * 0.95;
      if (s > wordBest) wordBest = s;
    }
    // 隣接ワードペア結合: "Rip-Stop" → "ripstop"（0.90倍ペナルティ）
    for (let k = 0; k < words.length - 1; k++) {
      const pair = words[k] + words[k + 1];
      const s = compareStrings(tLow, pair) * 0.90;
      if (s > wordBest) wordBest = s;
    }
    // 全ワード結合（0.88倍ペナルティ）
    const allJoined = words.join('');
    const sAll = compareStrings(tLow, allJoined) * 0.88;
    if (sAll > wordBest) wordBest = sAll;
  }
  return Math.max(direct, wordBest);
};
```

**設計意図:**
- スペース除去だけでは `"AA Battery"` → `"aabattery"` で `"batt"` の前方一致が消える
- 単語分割することで `"battery".startsWith("batt")` がヒットする
- ハイフン結合語 `"Rip-Stop"` → words `["rip","stop"]` → ペア結合 `"ripstop"` で `"sripstop"` にマッチ

### 5-3. matchOcrText

```js
const matchOcrText = useCallback((rawText) => {
  // [1] OCRテキストをトークン（単語）に分割
  const tokens = rawText
    .split(/\s+/)
    .map(w => w.replace(/[^a-zA-Z0-9\-]/g, '').trim())
    .filter(w => w.length >= 3);

  // [2] scoreToken: 1トークンに対して全アイテムをスコアリング
  const scoreToken = (token) => {
    const tLow = token.toLowerCase();
    const allCandidates = [];
    for (const item of apiData.items) {
      const nameForms = [item.name, item.shortName, item.nameEn, item.shortNameEn]
        .filter(Boolean).map(s => s.toLowerCase());
      let itemBest = 0;
      for (const cand of nameForms) {
        const candNoSp = cand.replace(/\s+/g, '');
        const s = Math.max(calcScore(tLow, cand), calcScore(tLow, candNoSp));
        if (s > itemBest) itemBest = s;
      }
      if (itemBest >= 0.30) allCandidates.push({ item, score: itemBest });
    }
    allCandidates.sort((a, b) => b.score - a.score);
    const top5  = allCandidates.filter(c => c.score >= 0.60).slice(0, 5);
    const loose = allCandidates.filter(c => c.score <  0.60).slice(0, 8);
    return {
      token,
      item: top5[0]?.item || null,
      score: top5[0]?.score || 0,
      topCandidates: top5,    // 確定候補（▼N候補ボタン）
      looseCandidates: loose, // 補完候補（未認識行の▼補完候補ボタン）
    };
  };

  // [3] 全トークンをスコアリング
  const tokenMatches = tokens.map(scoreToken);

  // [4] 同一アイテムを集計（アイテムID単位）
  const itemMap = new Map();
  const unmatchedTokens = [];
  for (const m of tokenMatches) {
    if (m.item) {
      if (itemMap.has(m.item.id)) {
        itemMap.get(m.item.id).qty++;
        itemMap.get(m.item.id).tokens.push(m.token);
      } else {
        itemMap.set(m.item.id, {
          item: m.item, qty: 1, tokens: [m.token],
          topCandidates: m.topCandidates,
        });
      }
    } else {
      unmatchedTokens.push({ token: m.token, looseCandidates: m.looseCandidates });
    }
  }

  // [5] マッチ済みトークンを未認識表示から除外
  const matchedTokenSet = new Set(
    Array.from(itemMap.values()).flatMap(e => e.tokens.map(t => t.toLowerCase()))
  );
  const purelyUnmatched = unmatchedTokens.filter(
    m => !matchedTokenSet.has(m.token.toLowerCase())
  );

  // [6] 結果配列: 未認識を先頭、マッチ済みを後ろ
  return [
    ...purelyUnmatched.map(({ token, looseCandidates }) => ({
      line: token, item: null, qty: 1, checked: false,
      topCandidates: [], looseCandidates,
    })),
    ...Array.from(itemMap.values()).map(({ item, qty, tokens, topCandidates }) => ({
      line: tokens.join(' '), item, qty, checked: true,
      topCandidates, looseCandidates: [],
    })),
  ];
}, [apiData.items]);
```

**照合対象フィールド:**

| フィールド | 説明 |
|-----------|------|
| `item.name` | 日本語名（API `lang: ja`） |
| `item.shortName` | 日本語略称 |
| `item.nameEn` | 英語名（API `lang: en` で別途取得してマージ） |
| `item.shortNameEn` | 英語略称 |

### 5-4. runOcr

```js
const runOcr = useCallback(async () => {
  if (!ocrFile || ocrRunning) return;
  setOcrRunning(true);
  setOcrProgress(0);
  setOcrMatches([]);
  try {
    // [1] img要素が完全ロードされるまで待機
    const img = ocrImgRef.current;
    if (!img.complete || img.naturalWidth === 0) {
      await new Promise((resolve, reject) => {
        img.onload = resolve;
        img.onerror = () => reject(new Error('画像の読み込みに失敗しました'));
        setTimeout(() => reject(new Error('タイムアウト')), 10000);
      });
    }

    // [2] 画像前処理（Canvas）
    const SCALE = 4;                                   // 4倍拡大（小フォント対策）
    const W = img.naturalWidth, H = img.naturalHeight;
    const cropH = Math.max(10, Math.round(H * ocrCropRatio)); // 上部N%のみ切り取り
    const canvas = document.createElement('canvas');
    canvas.width = W * SCALE;
    canvas.height = cropH * SCALE;
    const ctx = canvas.getContext('2d');
    ctx.imageSmoothingEnabled = true;
    ctx.imageSmoothingQuality = 'high';
    ctx.drawImage(img, 0, 0, W, cropH, 0, 0, W * SCALE, cropH * SCALE);

    // グレースケール変換（アイコンの色ノイズを除去）
    const imageData = ctx.getImageData(0, 0, W * SCALE, cropH * SCALE);
    const d = imageData.data;
    for (let i = 0; i < d.length; i += 4) {
      const gray = 0.299 * d[i] + 0.587 * d[i+1] + 0.114 * d[i+2];
      d[i] = d[i+1] = d[i+2] = gray;
      d[i+3] = 255;
    }
    ctx.putImageData(imageData, 0, 0);
    const dataUrl = canvas.toDataURL('image/png');

    // [3] Tesseract.recognize() でOCR実行
    const { data: { text } } = await Tesseract.recognize(
      dataUrl, 'eng',
      {
        logger: m => {
          if (m.status === 'recognizing text')
            setOcrProgress(Math.round(m.progress * 100));
        },
        tessedit_pageseg_mode: '11',  // PSM 11: 疎なテキスト（スタッシュのラベル向け）
        tessedit_char_whitelist: 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789- ',
      }
    );
    setOcrProgress(100);
    setOcrMatches(matchOcrText(text));
  } catch (e) {
    alert('OCR実行中にエラーが発生しました: ' + (e.message || String(e)));
  } finally {
    setOcrRunning(false);
  }
}, [ocrFile, ocrRunning, matchOcrText, ocrImgRef, ocrCropRatio]);
```

**前処理の設計理由:**

| 処理 | 理由 |
|------|------|
| 4倍スケールアップ | EFTスタッシュのラベルは小さく (~10〜14px)、Tesseractの最低推奨解像度を確保 |
| 上部N%クロップ | アイコン画像がOCRノイズになるため、ラベル行だけを切り出す |
| グレースケール変換 | アイコンの色情報を除去してテキスト認識精度を上げる |
| 2値化なし | 閾値2値化は文字のアンチエイリアス部分が「輪郭だけの文字」になる問題を起こすため採用しない |
| PSM 11 | スタッシュのラベルは等間隔に散在する「疎なテキスト」のため |
| 言語 `eng` のみ | EFTのUIフォントは英字ベース。`jpn` モデルは誤認識が多発 |

### 候補ドロップダウンの仕様

**確定候補（マッチ済み行）:**
- スコア ≥ 0.60 の上位5件
- 黄色ボタン「▼ N候補」
- 現在選択中に ✓ マーク
- スコア% を表示

**補完候補（未認識行）:**
- 0.30 ≤ スコア < 0.60 の上位8件
- 青色ボタン「▼ 補完候補 N件」
- 選択すると行がマッチ済みに昇格（checked: true になる）
- **補完候補0件の未認識行は一覧に表示しない**（ノイズ削減）

**共通:**
- ドロップダウン外クリックで自動的に閉じる
- `e.stopPropagation()` でドロップダウン内クリックが外クリックイベントを発火させないよう制御

### 11-2. 補完候補0件の未認識行を非表示


## 9. 既知の問題・今後の課題

### 未解決
